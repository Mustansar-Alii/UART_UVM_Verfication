This project implements a complete UVM-based verification environment for UART protocol using SystemVerilog.

The verification environment supports:
- Randomized baud rate testing
- Variable data length (5–8 bits)
- Parity enable/disable
- Odd/Even parity
- Single and double stop bits
- UART transmitter and receiver verification
- Functional checking using scoreboard

## Features

- UVM Testbench Architecture
- Configurable UART Parameters
- Randomized Sequences
- Driver, Monitor, Scoreboard
- Agent and Environment
- Protocol Verification
- RTL + UVM Separation
- Self-checking Testbench
